# Contribution Guidelines

First off, thank you for considering contributing to Awesome Computer Architecture! 

Please ensure your pull request adheres to the following guidelines:

- Search previous suggestions before making a new one, as yours may be a duplicate.
- Make sure the link is functional (no 404s).
- Ensure the item is highly relevant to Computer Architecture.
- Keep descriptions short, clear, and objective.
- Add the item to the correct category in alphabetical order.

**Format:**
`- [Name](link) - Description.`
(Description must start with a capital letter and end with a period).

## Link quality

Always link the canonical, primary source for a resource.

- No search-result URLs (YouTube, Google, GitHub search, or similar query pages). They are unstable and vary by user, region, and ranking.
- Courses: link the official course page, not a video platform channel.
- Videos: link a specific official talk or playlist, never a search query.
- Software: link the official repository or documentation.
- Specifications: link the standards body's official page.
- Papers: link the publisher, DOI, or official preprint.
- Link the specific resource page, not a department or organisation homepage.
- No URL shorteners, tracking parameters, or link aggregators.
- Label third-party mirrors as mirrors, and superseded projects as legacy.
- Prefer HTTPS wherever the host supports it.

The entry's description must accurately state what the link *is*. A working URL that points to the wrong kind of resource (a simulator listed as a trace set, a homepage listed as a dataset) is still a defect.

Thank you for your suggestions!
